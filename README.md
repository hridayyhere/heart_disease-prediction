# heart_disease-prediction


This project predicts the presence of heart disease in a patient based on medical attributes, using machine learning classification models.

## 📊 Dataset
- **Source:** [UCI Heart Disease Dataset](https://archive.ics.uci.edu/ml/datasets/Heart+Disease)
- The dataset contains 303 instances with 14 attributes like age, sex, chest pain type, resting blood pressure, cholesterol, etc.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib / Seaborn
- Google Colab

## 🚀 How to Run
1. Clone this repository or download the `.ipynb` notebook.
2. Open `heart_disease_prediction.ipynb` in Google Colab .
3. Run all cells step-by-step.
4. The notebook performs:
   - Data exploration & cleaning
   - Feature selection
   - Model training (Logistic Regression / Random Forest / etc.)
   - Evaluation (accuracy, confusion matrix)

## 📝 Project Details
- The goal is to predict whether a patient has heart disease (binary classification).
- Trained multiple models and selected the best based on accuracy.
- Achieved accuracy of **85%**.
